# TITÁN Open Core

TITÁN Open Core is an early-stage open-source fitness platform focused on training planning, nutrition organization and progress tracking.

The project is being built in public as a clean, modular foundation that can evolve through documentation, testing and community contributions.

## Current scope

- basic training planning;
- simple nutrition examples;
- progress tracking;
- responsive dashboard interface;
- modular React + TypeScript foundation.

## Project direction

This repository represents the public core of TITÁN. The goal is to keep the project useful, understandable and extensible while continuing to develop new capabilities over time.

The current version is intentionally simple and should be considered a starting point rather than a finished product.

## Run locally

```bash
npm install
npm run dev
```

## Roadmap

- persistent local data;
- richer training planning;
- nutrition customization;
- import/export;
- accessibility improvements;
- modular exercise library;
- testing and CI;
- documented extension points;
- community-driven features.
